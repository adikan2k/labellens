2026-11-25T21:28:09+00:00 · embeddings `voyage-4-lite` · 1,019 explainers · 145 queries from `evals/datasets/retrieval.jsonl`

Does the ask agent's `search_explainers` tool put the right explainer in the 5 it returns? The agent's search looks up any E-number in the question exactly, then adds the nearest explainers by vector (cosine, exact, on the committed vectors). Vector alone is how the tool worked before the E-number lookup; keyword is BM25 on the same text; hybrid fuses vector and keyword (reciprocal rank fusion). Generated by `uv run python -m evals.runners.retrieval_eval`.

Ranges in brackets are 95% confidence intervals (Wilson score): with this few cases the true rate could plausibly be anywhere in the range, so a gap smaller than the ranges may be noise. MRR ranges are a bootstrap over queries.
